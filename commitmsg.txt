regions: group a collapse by identity, not by a contiguous run

The grouping model was the real defect. It looked for the longest CONTIGUOUS
periodic run — period p: rest[j] === rest[j-p] — and emitted one template per
phase. A real feed has no periodic run, so the scan fragmented and paid a full
template per phase boundary: on x.com/home the timeline's children are
[A, B, A, A, A, A, A] (A = six posts, B = one post behind an extra wrapper), the
best it could find was period 3 spanning 4, and it printed THREE full post
templates to describe five items. 137 lines / 7,013 B for a feed in which every
child is data-testid=cellInnerDiv.

A collapse now GROUPS BY IDENTITY (name + shape) across the whole child list.
Order comes from first appearance. A feed does not need to be periodic to be a
feed. Because a group's members share the key they share the name by
construction, so the "collapsed run lists every distinct name" clause became
vacuous — and nothing can be hidden by a collapse.
